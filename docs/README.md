# Project documents

The AIDLC pipeline writes and updates these documents through pull requests. Each one is approved at its
gate before work that depends on it starts.

| Path | Stage | Owner |
|---|---|---|
| `spec/business.md` | Business logic spec | BA/PO |
| `spec/technical.md`, `spec/units.yaml`, `api/openapi.yaml` | Technical spec and API contracts | Tech Lead |
| `tests/backend/` | Backend and API test cases | QA |
| `plan/` | Baseline task breakdown | Tech Lead, PM |
| `design/<screen>/` | Screen designs | Design Lead |
| `tests/ui/` | UI test cases | QA |
| `retro/` | Sprint retrospectives | PM |
